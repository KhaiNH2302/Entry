        Tài liệu tích hợp hệ thống QLTS – OGL – Core Banking

1. Mục tiêu

Tài liệu mô tả chi tiết luồng nghiệp vụ, API tích hợp giữa hệ thống QLTS (Hạch toán kế toán), hệ thống OGL và Core Banking VietinBank nhằm phục vụ các nghiệp vụ: vấn tin tài khoản, quản lý NCC, tạo chứng từ AP, thanh toán, hạch toán GL và chuyển tiền.

Tài liệu mô tả logic xử lý, mapping dữ liệu, luồng tích hợp, sequence diagram, và mapping API – Database – Logic cho hai nghiệp vụ:



Tạm ứng (TU)



Thanh toán (TT)



Áp dụng cho 3 hệ thống:



QLTS (Hạch toán kế toán) – Hệ thống sinh logic, tính toán bút toán, quản lý phiếu.



OGL – Hệ thống ghi nhận bút toán kế toán.



Core Banking – Hệ thống thực hiện chuyển tiền và vấn tin tài khoản.

4.2 Vấn tin tài khoản Core Banking

API: A382_MSA_PRF_DEP_INQ v1.0.0

Mục đích: Lấy tên chủ tài khoản để giảm rủi ro nhập sai.

Input chính:



data.acctId: Số tài khoản thụ hưởng.



data.type = "1" (truy vấn tài khoản).



data.debOrCre = "C".



Output chính:



data.acctName: Tên chủ tài khoản.



data.stat: Trạng thái tài khoản.




Ví dụ từ tài liệu: “data.acctName”: “Customer Name”


QLTS lưu kết quả vào phiếu đề nghị.

4.3 Vấn tin / tạo mới NCC trên OGL

4.3.1 Vấn tin NCC

API: GET /vendors/site-info

Input: entity, vendorName, vendorNumber, vendorSiteCode.

Output: Danh sách NCC và site.

Nếu NCC chưa tồn tại, chuyển sang bước tạo mới.

4.3.2 Tạo mới NCC

API: POST /vendors/site

Input: Thông tin NCC + các segment hạch toán (dr/cr).

Output: vendorId, vendorSiteId, status.

QLTS lưu vendorNumber + vendorSiteCode vào phiếu đề nghị.

4.4 Phê duyệt phiếu thanh toán

Người dùng phê duyệt phiếu → QLTS cập nhật trạng thái "Đã phê duyệt".

4.5 Gửi chứng từ AP sang OGL

4.5.1 Tạo mới chứng từ AP

API: POST /ap/create-invoice

Input chính:



vendorNumber, vendorSiteCode, entity.



invoiceLineList: Các dòng hạch toán.



vatList: Danh sách hóa đơn VAT.



Output: transactionId, requestId.

4.5.2 Thanh toán chứng từ AP đã có

API: POST /ap/create-payment

Input: invoiceNumber, amount, maker, checker.

Output: transactionId, requestId.

4.6 Gửi lô hạch toán GL

API: POST /general-ledger/interface

Input:



RequestId, AccountingDate, CurrencyCode, BranchCode.



Danh sách Line gồm 7 segment + số tiền Nợ/Có.



Output: transactionId.

4.7 Chuyển tiền qua Core Banking

QLTS xác định kênh chuyển tiền: nội bộ VietinBank hoặc CITAD.

4.7.1 Chuyển tiền nội bộ

API: A382_MSA_TRANSFER_IN v1.0.0

Input chính:



depAcctIdFrom: Tài khoản ghi nợ.



depAcctIdTo: Tài khoản thụ hưởng.



amount, notes, feeInfo.



Output: trnRefNum, hostRefNum, postedDt.

4.7.2 Chuyển tiền CITAD

API: A382_MSA_TRANSFER_OUT v1.0.0

Input chính:



toAcctId, toBankId, toBranchId, amount[].



trnDesc: Nội dung giao dịch.



Output: statusCode, hostRefNum, pmtStatus.

QLTS cập nhật phiếu: "Đã thanh toán".

4.8 Tra cứu trạng thái hạch toán OGL

API: POST /batch/status

Input: transactionId.

Output: status = COMPLETED | PROCESSING | ERROR | NOT_FOUND.
